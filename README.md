laugh-line is a tiny program that writes one funny line about everyday life to a file: noise-cancelling headphones, bought to hear oneself think, end up amplifying the one sound left — the wearer's own chewing.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
